mend is one command-line tool that applies the edits AI models write, in four formats — unified diffs (with wrong line numbers), SEARCH/REPLACE blocks, V4A patches, and text-editor tool calls as JSON — to a tree of text files, matching lines at three tiers of whitespace tolerance, re-indenting drifted edits, and changing every file or nothing at all.

## Run it

```sh
node main.ts [options] [PATCH]
```
